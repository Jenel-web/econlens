# Project: EconLens. 
# Goal: 
- Bridge news with economic impact. Stack: Flutter + Spring Boot. Speciality: 
- Geopolitical and Macro-economic inference.

## Tech Stack
- Backend: Python + FastAPI
- Database: Supabase
- Frontend: Flutter (Mobile)
- AI Engine: Gemini 3 Flash / Spring AI

## Rules
- Always use Clean Architecture.
- Backend must expose REST APIs for the Flutter app.
- Never hardcode API keys; use environment variables.
- All AI logic must follow the protocols in the SKILL.md files.
- Goal: Use AI to predict "Household Pressure" from news headlines.
- Logic: Follow the rules defined in `SKILL.md`.
